GATK4 germline variant calling

A Nextflow pipeline following the GATK Best Practices for germline short variants, benchmarked on GIAB HG002.

code on GitHub · README

The pipeline

Nextflow DSL2, one module per tool, every step in Docker. The same run works on a laptop, SLURM or AWS Batch by changing the profile.

BWA-MEMalign + read groups, sorted BAM
MarkDuplicatesflag PCR/optical duplicates
BaseRecalibratorBQSR model from known sites
ApplyBQSRrecalibrated base qualities
HaplotypeCallergVCF per sample (-ERC GVCF)
MultiQCduplication metrics report

Benchmark: GIAB HG002, chromosome 20

Hard filters are the GATK-recommended thresholds (SNPs: QD<2, QUAL<30, SOR>3, FS>60, MQ<40, MQRankSum<-12.5, ReadPosRankSum<-8; indels: QD<2, QUAL<30, FS>200, ReadPosRankSum<-20), applied outside the pipeline. BWA 0.7.19, GATK 4.6.2.0, Nextflow 26.04.6, 2 CPUs, 7 GB RAM. Full write-up in PR #1.
